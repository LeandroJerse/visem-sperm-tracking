# Fontes de dados

Conteúdo externo e imutável. Não editar arquivos para corrigir resultados.

- `visem/videos/`: 85 vídeos originais;
- `visem/clinical/`: tabelas clínicas por participante;
- `visem/metadata/`: inventário e descrição do VISEM;
- `visem_tracking/dataset/Train/`: 20 vídeos com boxes, classes e IDs;
- `visem_tracking/metadata/`: tabelas auxiliares do conjunto anotado.

Conversões e caches pertencem a `../derived/`.
