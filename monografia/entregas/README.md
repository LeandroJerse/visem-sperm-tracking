# Entregas acadêmicas

- `pdf/` preserva os PDFs efetivamente entregues nas etapas E2–E5.
- `arquivos-fonte/` preserva pacotes-fonte enviados junto às entregas.

Esta pasta é um registro acadêmico, não uma pasta de compilação. Arquivos
auxiliares de LaTeX e renders de conferência não devem ser mantidos aqui.
Novas versões de trabalho são compiladas a partir da fonte em `monografia/`;
somente uma entrega real deve ser arquivada nesta área.
