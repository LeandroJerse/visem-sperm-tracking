# Configurações congeladas

Uma configuração entra aqui somente depois de concluída a seleção no conjunto
de validação. Depois da primeira execução no teste, o arquivo não pode ser
alterado; qualquer mudança cria uma nova configuração e um novo identificador.

O diretório contém apenas configurações efetivamente promovidas. Algoritmos
ainda não avaliados não recebem pastas ou READMEs placeholder.
