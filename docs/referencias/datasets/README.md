# Referências dos datasets

## VISEM

- Registro oficial: [Zenodo 2640506](https://zenodo.org/records/2640506)
- Cópia local de referência: `VISEM_Dataset.pdf` (não versionada).
- Uso no projeto: 85 vídeos, metadados do vídeo e tabelas clínicas; os 65 sem
  tracking manual entram apenas na aplicação posterior à validação.

## VISEM-Tracking

- Registro oficial: [Zenodo 7293726](https://zenodo.org/records/7293726)
- Cópia local de referência: `VISEM_Tracking.pdf` (não versionada).
- Uso no projeto: 20 vídeos com caixas, classes e IDs persistentes para treino,
  validação, teste bloqueado e confirmação 5-fold.

Os PDFs desta pasta são referências documentais. Os dados utilizados pelo
pipeline permanecem em `data/sources/` e não devem ser editados.
